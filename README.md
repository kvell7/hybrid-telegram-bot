# Бот сверки Telegram и Google Таблицы

Первая версия. Она присылает отчёт и по умолчанию никого не блокирует. Код открывать не нужно. Секреты в эти файлы вставлять нельзя.

## Что делает

- Читает все листы таблицы, где есть столбец Telegram.
- Человек остаётся в списке, если его ник есть хотя бы на одном таком листе.
- Запоминает тех, кто написал сообщение или вошёл в подключённую группу.
- Раз в неделю и по запросу присылает отчёт в личку.
- Не приглашает людей в группу и не берёт почты в отчёт.
- Не получает от Telegram готовый список всех участников. Молчунов, которых бот ни разу не видел, он не заблокирует.

- Автопроверка: понедельник, 10:00, Europe/Moscow

Рабочая группа компании не подключена. Пока не включено ALLOW_NON_TEST, бот не заблокирует группу, в названии которой нет слова «тест» или test.

## Команды в личке с ботом

- проверка — сверить таблицу
- участники — кого бот уже запомнил
- статус — включены ли баны

В самой группе бот молчит. Это нормально.

## Настройки для сервера

Секретные значения храним только в Coolify:

- BOT_TOKEN — токен из BotFather
- GOOGLE_CREDENTIALS_JSON — весь текст файла-ключа, начинается с символа {

Остальное:

- SPREADSHEET_ID = 1XpNFbygNmZwOqjJkTYSAhtu0BnQplMon1RXUKO3grsE
- REPORT_CHAT_ID = 791088587
- GROUP_IDS = -1004351827165
- BANS_ENABLED = false
- ALLOW_NON_TEST = false
- TIMEZONE = Europe/Moscow
- CHECK_WEEKDAY = mon
- CHECK_HOUR = 10
- CHECK_MINUTE = 0
- DB_PATH = /data/bot.db
- GRACE_HOURS = 24
- MAX_BANS_PER_RUN = 30
- SHRINK_RATIO = 0.7
- SHRINK_MIN_PREVIOUS = 30

BANS_ENABLED нельзя ставить в true, пока несколько отчётов не будут правильными. За один запуск бот всё равно блокирует не больше 30 человек. Если список ников резко стал меньше чем на 70 процентов от прошлого успешного чтения, бот никого не блокирует.

На сервере нужна постоянная папка для базы, подключённая к /data. Без неё после перезапуска бот забудет всех, кого видел.
